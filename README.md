# Marks Industrial — React + TypeScript + Tailwind

Landing page industrial premium, inspirada na referência enviada.

## Rodar
npm install
npm run dev

## Build
npm run build

As imagens do protótipo usam URLs externas do Unsplash. Para produção, troque por fotos reais da fábrica, máquinas, peças e equipe.


## Vídeos
Crie a pasta `public/videos/` e coloque:
- `usinagem-cnc.mp4`
- `controle-qualidade.mp4`
- `dentro-da-fabrica.mp4`

A seção já abre os vídeos em um modal/tela cheia. Os posters são imagens da própria página e serão substituídos automaticamente pelos vídeos quando os arquivos estiverem presentes.
